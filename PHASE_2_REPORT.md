## Что сделано в 2.4

- Кэш обновляется по `storage`, есть подписка на значения и ошибки отложенной записи. Перед записью перечитывается актуальное значение. Запись откладывается на 300 мс, `pagehide` и скрытие вкладки вызывают синхронный flush.
- Результаты объединяются по ID. Для одной попытки сохраняется максимальный уровень подсказки, для нового номера подсказки начинаются заново. Счётчики не уменьшаются; завершённые номера попыток хранятся отдельно от обрезаемой истории, чтобы старая вкладка не вернула завершённый черновик.
- Черновики одной попытки выбираются по `updatedAt`, с детерминированным разрешением равенства. Новая отметка времени учитывает сохранённую, поэтому перевод системных часов назад не отменяет свежую правку. Для фильтра цели также есть время изменения, чтобы вкладки не переключали его бесконечно друг у друга.
- `breakdown` сохраняется цельным. При обнаружении раскрытого решения ремонт ограничивается 25/50, итог пересчитывается как сумма компонентов. У старых результатов без breakdown вычисляемый fallback не объявляется явно сохранёнными компонентами: это не даёт ему вытеснить настоящий разбор из другой вкладки.
- Подсказки перепроверяются перед отправкой оценки и при записи результата; учитывается ситуация, когда другая вкладка раскрыла решение во время работы воркера.
- Миграция учебного конверта v1→v2 реализована таблицей переходов и последующей проверкой данных. Неизвестная будущая версия запускается с пустым состоянием в памяти; любые дальнейшие записи, включая закрытие страницы, оставляют исходный ключ побайтно неизменным. E2E проверяет все три режима.
- `restoreTrial` удаляет только повреждённые submissions и сохраняет исправную историю при сбросе текущего задания. **У `Progress` нет поля submissions**: для него независимо сохраняются исправные строки, формула, доказательство ошибки и счётчики; невозможное завершение снимается. Новая история в этот режим не добавлялась.

## Принятые решения и ограничения

- Подсказки и попытки объединяются максимумом в рамках одной попытки; при конфликте тел черновика действует более позднее изменение. Для равных меток выбран детерминированный порядок. Явные компоненты результата имеют приоритет над отсутствующими старыми компонентами.
- Один зависший воркер завершает все ещё ожидающие запросы этого воркера с кодом timeout; следующий запрос создаёт новый. Обычная отмена затрагивает только свой промис.
- Прежний допуск ничьей 1e-9 сохранён; строгий независимый тест не меняет это бизнес-правило.
- Синхронизация вкладок — последующее согласование через localStorage и storage events, **не атомарная транзакция**. Гарантия сохранности при одновременном аварийном завершении всех вкладок не заявляется. Объединение истории между вкладками реализовано для учебного режима, как требует задача; у старых режимов улучшены восстановление, debounce, кэш и защита версий.
- Firefox/WebKit настроены, но не запускались. Проверка CI не выполнялась: это задача 4.3. Визуальная регрессия без утверждённого эталона не заявляется.
