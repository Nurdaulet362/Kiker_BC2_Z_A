### Текущие маршруты

| URL | Что открывается сейчас |
| --- | --- |
| `/` | Учебная главная |
| `/#progress` | Прогресс и история |
| `/#lesson/revenue-cancelled` | Первый урок |
| `/#lesson/<id>` | Выбранный урок |
| `/#review/<id>` | Сохранённый разбор |
| `/#practice` | Редирект с заменой записи истории на `/#lesson/revenue-cancelled` |

Редирект работает при прямом открытии старого URL и при изменении hash в уже открытой странице. `location.replace` заменяет устаревшую запись истории, поэтому возврат не ведёт в цикл редиректа. Старые ключи `fix-the-report.cancelled-orders.v1` и `fix-the-report.work-trial.v1` не удаляются и не мигрируются редиректом; черновик первого урока восстанавливается отдельно. Все три прежние ссылки из Work Trial теперь ведут прямо в первый урок. Сами задания Work Trial не изменены.

`src/App.tsx` не удалять: `Workspace.tsx` импортирует из него `Modal`. `src/model.ts` нужен Simulation. Закрытие Work Trial пейволом относится только к необязательной задаче 4 нового спринта.

## Важные контракты состояния

- Язык: существующий ключ `fix-the-report.language`, значения `en` и `ru`. Не переименовывать без миграции.
- Учебное состояние: `fix-the-report.learning.v2`. История ограничена последними 100 результатами; счётчики попыток и сведения о подсказках живут отдельно.
- Данные `#practice`, `#trial` и нового учебного пути хранятся раздельно.
- Изменения черновика записываются с задержкой 300 мс; запись сбрасывается при скрытии/уходе со страницы. При отказе хранилища действует память открытой страницы с видимым предупреждением.
- Результаты согласуются по ID; закрытые попытки, счётчики, `hintLevel`, раскрытие решения и `breakdown` должны сохранять смысл при конфликтах вкладок.
- Новая попытка хранит снимок отправленных данных и решения. Изменение черновика не переписывает прошлый результат.
- Неизвестную будущую версию хранилища нельзя молча перезаписывать текущей.
- Перед потерей данных сохраняются две последние отличающиеся исходные строки: `.backup` и `.backup.prev`. Подтверждённое штатное закрытие черновика не должно вытеснять полезную копию.
- Операции localStorage не являются атомарной транзакцией между вкладками. Две копии не заменяют серверную синхронизацию или бессрочный журнал.

Подробности: [storage-merge.md](storage-merge.md). Будущие недельные метаданные H6a нужно хранить независимо от обрезаемой истории результатов; сейчас этих полей нет.

## Проверка формул и оценка

Формулы действительно вычисляются в ограниченном табличном окружении. Произвольный JavaScript не исполняется; список функций задан явно. `SUMIFS` и `COUNTIFS` сейчас не поддерживаются. Успех на контрольных наборах не означает полную совместимость с Excel.

В новом учебном пути: диагностика 20 + исправление до 50 + перенос 30. Зачёт требует всех проверок исправления, верного переноса, суммы не меньше 80 и отсутствия раскрытого решения. После раскрытия исправление ограничено 25/50, итог — максимум 75/100.

Для денежных ответов движок уроков использует допуск меньше половины цента; текущая `expectedLessonValue` суммирует числа и округляет итог. Это не следует описывать как единый целочисленный денежный движок всего проекта. В H4 отдельно задан контракт целых центов и перекрёстного умножения для генерации вариантов.

H0b клонирует payload до запуска воркера. Ошибка клонирования одного запроса не должна завершать соседний запрос или менять срок его watchdog.

## Локальный запуск

Из корня репозитория:

```sh
npm ci
npm run dev -- --port 5173 --strictPort
```

Открывать [http://127.0.0.1:5173/](http://127.0.0.1:5173/). Нужен работающий процесс Vite. Двойной щелчок по `index.html` и адрес `file://...` не заменяют сервер. При занятом порте сначала проверить, какой процесс его использует; не останавливать неизвестный процесс автоматически.

Проверки при изменениях реализации:

```sh
npx tsc -b
npm test
npm run build
npm run preview -- --port 4173 --strictPort
```

После готовности preview, в другом терминале:

```sh
PLAYWRIGHT_BASE_URL=http://127.0.0.1:4173 npm run test:e2e
```

Для первого запуска Playwright может понадобиться `npx playwright install chromium`. Если 4173 занят, использовать свободный порт и тот же порт в `PLAYWRIGHT_BASE_URL`. Этот параметр нужен, чтобы e2e проверяли собранный `dist/`, а не автоматически запущенный dev-сервер.
