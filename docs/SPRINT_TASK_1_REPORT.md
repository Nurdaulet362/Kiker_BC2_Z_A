5. Существующий тест `verifies every intended solution against its report and independent edge cases` в `tests/learning.test.ts` проверяет все шесть эталонных решений; он прошёл в общем наборе. Новый тест не добавлен из-за остановки реализации. Четыре урока формульные, два — задания на решение.

Команда воспроизведения из корня репозитория:

```sh
node --input-type=module <<'JS'
import FormulaParser from 'fast-formula-parser';
const data = [
  ['Order', 'Status', 'Amount'],
  ['M-101', 'Paid', 480], ['M-102', 'Paid', 320],
  ['M-103', 'Cancelled', 650], ['M-104', 'Paid', 400],
  ['M-105', 'Pending', 180],
];
const parser = new FormulaParser({
  onCell: ({ row, col }) => data[row - 1]?.[col - 1] ?? null,
  onRange: ({ from, to }) => Array.from({ length: to.row - from.row + 1 }, (_, r) =>
    Array.from({ length: to.col - from.col + 1 }, (_, c) => data[from.row + r - 1]?.[from.col + c - 1] ?? null)),
});
for (const formula of [
  'SUMIFS(C2:C101,B2:B101,"Paid")',
  'SUMIFS(C2:C101,B2:B101,"Paid",C2:C101,">300")',
  'COUNTIFS(B2:B101,"Paid")',
  'COUNTIFS(B2:B101,"Paid",C2:C101,">300")',
  'SUMIF(B2:B101,"Paid",C2:C101)',
  'SUMIF(B2:B101,"paid",C2:C101)',
  'COUNTIF(B2:B101,"Paid")',
  'COUNTIF(B2:B101,"paid")',
]) {
  try {
    console.log(JSON.stringify({ formula, value: parser.parse(formula, { row: 103, col: 3, sheet: 'Orders' }) }));
  } catch (error) {
    console.log(JSON.stringify({ formula, error: error.message }));
  }
}
JS
```
